# Lapa vigIA

Sistema de protección antifraude para Telegram, desarrollado para el Dojo AI Hackathon (20-22 noviembre 2026).

## Estado inicial
Repositorio creado el 15 de noviembre de 2026, previo al inicio del hackathon.

## ¿Qué es Lapa vigIA?
Sistema multicapa de ciberseguridad que previene estafas digitales desde Telegram. Analiza texto, imágenes, URLs, números telefónicos y códigos QR para generar un score de riesgo 0-100.
